# Agriboost dashboard

>Agriboost dashboard for managing business event candidates

## Technologies

|     Technologie    |     Version     | 
| ------------- | :-----------: | 
| react      | 17.0.2 | 
| redux      |   4.0.5    |   
| material-ui|   4.11.0    |   
| material-table|  1.69.2    |  

## Installation

```
git clone https://github.com/HamdiNawfel/agriboost-dashboard.git
npm install
npm start

```

## Environment variables


```
REACT_APP_API_URL=http://api_url...
```
